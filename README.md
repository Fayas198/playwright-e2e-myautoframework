# playwright-e2e-myautoframework

Git Configuration

Git was configured with global username and email
to track commit authorship.

Commands used:

git config --global user.name
git config --global user.email



Framework Configuration

Playwright configuration was customized to support:

- Base URL setup
- Cross browser testing
- Parallel execution
- Retry strategy
- Screenshot on failure
- Video recording
- Trace debugging
- HTML reporting
